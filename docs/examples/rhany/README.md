# rhany (example / drop-in)

Raw RunningHub endpoint calls (`rhany.run`). Local `files` resolve under the current session root via `$SESSION`, then `$DATA` / `$PLUGIN`. See [INSTALL.md](INSTALL.md) to replace the home copy on KOMPUTER.

This tree is reviewable in the repo. It is not enabled as a bundled plugin; installing it means copying it into `$SINTY_HOME/plugins/rhany`.
