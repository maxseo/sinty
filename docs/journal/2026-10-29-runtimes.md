# One plugin installs FFmpeg, Python and ImageMagick

HyperFrames looked for Chrome, FFmpeg, Python and ImageMagick on PATH. Chrome is already the Playwright build used by `web.screenshot`. The others were not installed.

## What changed

Plugin `runtimes` installs FFmpeg, Python 3.12 and ImageMagick with winget for the current user. It reports the Playwright Chromium path and does not download a second browser. `hyperframes.render` sets `PUPPETEER_EXECUTABLE_PATH` to that file.

## Why

Those programs are machine tools. A separate plugin for each one would only repeat the same winget call.
