# 2026-11-12 — Плагин «Локальные модели»

Settings → Модели получает субвкладку через общее поле `ui.tabs.group: "models"` (не хардкод плагина). Плагин держит файлы, профили и один процесс llama-server в `$SINTY_HOME/data/local-models`. Большие GGUF заливаются потоком в `POST /v1/plugin-data/:plugin/uploads`. Запись в каталог агентов — аддитивный `POST /v1/models/bindings`, без затирания других провайдеров и fallback.

Автоустановка llama.cpp и несколько одновременных серверов, загрузка с Hugging Face и локальный коннектор с ПК клиента в эту версию не входят.
