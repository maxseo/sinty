## Транзакция plugin update
check version/compatibility -> показать changelog+permissions -> owner approval -> download bounded -> проверить подпись/hash -> безопасно распаковать в новый version dir -> parse/schema/entry checks+tests -> quiesce только этот plugin -> atomic activation -> readiness -> receipt/history. Предыдущую версию/config/data оставить. Неизвестный outcome/health failure: откат активации, не удаление data. Запрет traversal, absolute/drive/UNC paths, symlink/hardlink/junction escape, duplicate/case-conflicting paths, zip bombs; ограничения compressed/unpacked bytes/file count/depth. Не выполнять install lifecycle scripts/произвольные migration hooks от непроверенного издателя. Dependency supply chain входит в подписанный materialized/locked artifact, а не npm latest на клиенте.
