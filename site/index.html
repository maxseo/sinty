Sinty 1.0

Протокол sinty/1.0 заморожен. Новые поля добавлять можно. Переименовать или убрать поле — только в следующей мажорной версии. Версию отдаёт GET /v1/health.

Запуск

  1. node scripts/stage.mjs, затем install.ps1 или install.sh.
  2. В ~/.sinty/config.yaml строка models.default, например deepseek/deepseek-chat.
  3. sinty secret set deepseek, затем sinty web.

Плагины

Каталог установки: registry/plugins.json. Команда sinty plugins показывает, какой включён. Включение — имя в plugins.enabled и перезапуск. Свой плагин — папка в ~/.sinty/plugins.

Ход

Модель либо отвечает текстом, либо зовёт инструмент. Результат возвращается модели. Журнал хода — вкладка «Журнал» в чате. Спецификация событий: docs/spec/protocol.md в репозитории.
