# Локальные модели

Плагин управляет **одним** процессом `llama-server` на той машине, где запущен Sinty (локальная Windows-сборка или VPS/контейнер). Браузер только показывает интерфейс: файлы и GPU чужого компьютера из облачного окна недоступны.

## Что умеет эта версия

- Вкладка **Настройки → Модели → Локальные модели** (после включения плагина).
- Импорт GGUF потоком на диск (не целиком в память), отмена, проверка места, атомарная запись.
- Регистрация уже лежащего на **сервере** пути, без копирования.
- Профили запуска (контекст, GPU-слои, KV-кеш, параллельность, порт).
- Запуск и остановка только своего процесса, статусы остановлена / загружается / готова / ошибка. Зелёный — когда `GET /health` вернул 200.
- Постоянная запись в каталоге агентов: остановка или смена порта её не удаляет.
- Выбор уже установленного бинарника `llama-server` через интерфейс. Команды собираются из полей, не из строки shell.

## Что не входит

- Несколько одновременно работающих моделей.
- Скачивание с Hugging Face.
- Автозапуск сервера при включении плагина (выключен).
- Автоустановка `llama.cpp` из GitHub: сборки больше лимита сетевого API плагина, поэтому в этой версии укажите путь к бинарнику на машине Sinty.
- Запуск модели на ПК клиента из облачного Sinty (для этого нужен отдельный локальный коннектор).
- Автоматическое включение tool calling или зрения: это зависит от модели и шаблона чата.

## Данные

Реестр, веса и журналы хранятся в `$SINTY_HOME/data/local-models` и переживают обновление приложения и пересборку образа. Lifecycle OFF останавливает управляемый процесс и не удаляет файлы и записи каталога.

## Права

Просмотр вкладки: `ui:local-models/models` (view). Импорт, запуск и остановка: edit на том же праве. Добавление в каталог агентов: ещё `settings:models` (edit).
