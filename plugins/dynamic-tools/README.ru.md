# Динамичные инструменты

Плагин-обёртка над штатными `openai-compat`, `anthropic`, `openai-responses`. Ядро, SDK, схемы журнала и адаптеры не меняются; системное исправление имён RunningHub сохраняется. В списке включённых плагинов этот плагин должен стоять **раньше провайдеров**.

Откройте отдельный раздел бокового меню **«Динамичные инструменты»** (`#/t/dynamic-tools/settings`). Собственный переключатель режима изначально **выключен**, срок активации — **на чат**. Закреплены `fs.list`, `fs.read`, `skill.read`, но только если соответствующий инструмент действительно разрешён входящему запросу. Вы можете выбрать другие инструменты через поиск и группы плагинов: «Всегда в контексте».

При ON модель видит настоящие схемы закреплённых и активированных инструментов плюс `dynamic-tools.search`. Поиск принимает имя или русское/английское описание, возвращает короткие метаданные и добавляет настоящие схемы найденного **в следующий обычный запрос**. Сам поиск ничего не исполняет; универсального диспетчера команд нет. Закреплённое исключено из поискового пула.

«На чат» сохраняет имена до сброса/нового чата; «На ближайший запрос» использует их один раз, сохраняя выбор в пределах того же логического fallback, в том числе при сокращении старого результата инструмента ядром. Успешный повтор поиска после восстановления не активирует его заново. После падения процесса уже использованный запрос не воссоздаётся: это не продолжение генерации у провайдера. Изменения закреплений касаются новых логических запросов и не отменяют текущие вызовы.

Собственный OFF со следующего запроса передаёт полный входящий разрешённый каталог без изменений и без служебных подсказок. При этом загруженный плагин всё ещё регистрирует один инструмент поиска; это не удаление плагина и не побайтовое возвращение реестра до установки. Обычная кнопка выключения плагина останавливает процесс; обратное включение помещает его после провайдеров и может лишить обёртку приоритета. UI предупреждает, если обёртка ещё не наблюдала запросов. Порядок жизненного цикла не меняем.

**Без расширения прав.** Источник схем для выполнения — только `req.tools` текущего запроса. Глобальный список в интерфейсе — метаданные, а не разрешения. Поиск привязан к чату через доверенный контекст хоста и однозначный отпечаток запроса, не через аргументы модели; служебные маркеры не добавляются вообще. При одинаковых/неразличимых параллельных контекстах фильтрация безопасно обходится, старые поисковые представления отзываются; протоколы без обёртки не меняются. исходный каталог повторно пересекается с текущим. Если дочернему агенту не разрешён поиск или нет надёжной идентичности запроса, фильтрация обходится с его собственным полным каталогом. Недопустимый ответ с незаявленным инструментом заканчивается локальной ошибкой без исполнения, с сохранением присланного usage, без новых повторов. Отмена/сетевые ошибки не скрываются.

Веб-мост доступен только этому iframe: проверяет окно, opaque origin и nonce, делает два фиксированных GET через штатную авторизацию родительского UI и передаёт только имя, описание и группу. Токены, cookie, конфигурация, история, схемы и аргументы в iframe не передаются. Описания выводятся безопасным текстом.

Счётчики показывают полный/закреплённый/активированный/отправленный набор и байты JSON UTF-8 массива схем SDK **с учётом поиска**. Это не токены, не доллары, не вся история и не размер HTTP-запроса. Context Inspector остаётся до обёртки и видит полный набор. Обновите измерения после своего обычного запроса: плагин сам платных тестов не делает. Поиск может добавить шаг модели, ошибиться, ухудшить cache hits и планирование нескольких инструментов; на короткой задаче расход может вырасти. На длинном чате накопление схем уменьшает экономию.

На диске хранятся только настройки, имена активаций по чатам и ключи защиты от повтора: без текста, схем, аргументов и ключей провайдеров. Лимиты: 2048 чатов/живых билетов идентичности (30 мин), 4096 ожидающих поисков и ключей повтора на чат, до 12 совпадений; 200 последних агрегатов в памяти. Состояние не вытесняет выполняющиеся вызовы; при исчерпании — безопасный полный каталог либо явная локальная ошибка поиска. Есть кнопка сброса активации. Подробности и команды офлайн-тестов — в README.md.
