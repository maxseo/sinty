# Memory v1

Плагин помнит короткие утверждения отдельно для каждого пользователя и каждого агента. Вкладка «Память» появляется на карточке агента, когда плагин включён.

По умолчанию новый чат помнит другие чаты того же проекта и факты о пользователе. Другие проекты закрыты. Режим меняется на вкладке.

Запись идёт через `memory_v1.remember` и через строку пользователя `запомни: …`. Секреты не сохраняются. Поиск в ход попадает обычным блоком recall и не переписывает системный промпт.

Версия манифеста и `package.json` — одна и та же. Следующая версия ставится так:

```sh
node scripts/plugin-version.mjs bump memory-v1 0.2.0 "что изменилось"
```
