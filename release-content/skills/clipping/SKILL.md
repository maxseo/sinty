# Клиппинг — длинное видео в вертикальные клипы

Порт скилла `claude-shorts`. Авторский пайплайн сохранён, инструменты заменены на те,
что реально работают в песочнице Sinty. В песочнице нельзя `npm`, `npx`, `pip` и
`git clone`, поэтому оригинальные скрипты (faster-whisper, Remotion, MediaPipe) НЕ
используются: вместо них ffmpeg, python stdlib и HyperFrames.

## Что заменено и почему

| В оригинале | Здесь | Причина |
|---|---|---|
| faster-whisper (GPU) | SRT от человека, `diffusion.run transcribe` если подключён, иначе таймкоды вручную | STT-адаптера в песочнице нет |
| MediaPipe face track | `vision.look` по кадрам — центр лица ищем глазами модели | нет python-пакетов |
| Remotion рендер подписей | HyperFrames (HTML/Chromium) + ffmpeg | npm недоступен |
| NVENC | libx264 | нет GPU |
| `-c copy` нарезка | `-c:v libx264` после нарезки | склейки после snap требуют перекодировки кадров на границе |

## Пайплайн (10 шагов)

### 1. ПРЕФЛАЙТ
`ffprobe` входного файла: длительность, разрешение, fps, наличие звука, размер.
Если длительность меньше 60 с — сказать человеку, что клиппинг не нужен.
Рабочая папка: `_work/clips/`, результат: `_out/clips/`.

### 2. ТРАНСКРИПТ
По порядку:
1. Файл `.srt` рядом с видео — взять его.
2. `diffusion.run transcribe` если адаптер подключён (в песочнице отвечает «не подключено»).
3. Иначе — нарезка по кадрам: `hyperframes.frames` (fps 1, весь файл) и `vision.look`
   партией, просить «краткое содержание каждой минуты + таймкоды смены экрана».
   Это медленно, зато работает без STT.

### 3. ТИП КОНТЕНТА
Определить по кадрам: говорящая голова / запись экрана / подкаст / скринкаст с курсором.
От этого зависит раскладка.

### 4. ОЦЕНКА КАНДИДАТОВ
Читать рубрику `references/scoring-rubric.md`. Предложить 6–10 отрезков по 15–55 с.
Оценка по 5 осям с весами: хук 0.30, самостоятельность 0.25, эмоция 0.20,
плотность пользы 0.15, финал 0.10. Итог 0–100.

### 5. ПОКАЗ
Таблица: номер, таймкод, длительность, счёт, хук, почему работает.
Ждать выбор человека. Кнопки не нужны — просто спросить номерá.

### 6. УТВЕРЖДЕНИЕ
Уточнить границы словами («сдвинь 2 назад на 3 секунды»). Записать в
`_work/clips/approved.json`.

### 7. ПОДГОНКА ГРАНИЦ
Скрипт лежит в папке скилла, а `shell.run` туда не достаёт — сначала скопировать его
в проект: `skill.read_file` → `fs.write` в `_work/clips/snap_boundaries.py`. Потом:
`python _work/clips/snap_boundaries.py --video X --segments approved.json --out snapped.json`
Питон: `C:\Users\Maxseo\AppData\Local\Sinty\tools\python\python.exe`.
Скрипт: `ffmpeg silencedetect` находит паузы, старт сдвигается к ближайшей паузе
±1.5 с, конец продлевается на 0.3 с, границы зажимаются 5–60 с. Никогда не режем
посреди слова — режем по тишине.

### 8. ВЫРЕЗКА
```cmd
ffmpeg -y -ss START -to END -i IN.mp4 -c:v libx264 -crf 18 -preset veryfast -c:a aac _work/clips/clip_01.mp4
```

### 9. РЕНДЕР 9:16 С ПОДПИСЯМИ (HyperFrames)
Три раскладки — выбрать по кадрам, не наугад:
- **crop** — 9:16 в край, следить за лицом. Только одна говорящая голова на хорошем источнике.
- **split** — сверху экран, снизу увеличенное лицо. Для скринкастов с вебкамерой.
- **blur** — кадр целиком по ширине, фон размыт. Для широких планов, слайдов, нескольких людей.

Композиция: 1080×1920, кадры клипа лежат в `_out/frames/<seq>/`, `window.__render(t)`
чистая функция от `t`, подписи идут блоками по 2–4 слова с подсветкой активного.
Рендер: `hyperframes.render` с `fps:30, skipCli:true`, не длиннее 25 с за проход.

### 10. ЭКСПОРТ
- YouTube Shorts: H.264 High, 12 Mbps, AAC 192k
- TikTok: CRF 18, preset slow, AAC 128k
- Reels: 4.5 Mbps, maxrate 5000k, AAC 128k

Валидация после экспорта: файл играется, 1080×1920, звук не тишина
(`volumedetect` mean выше -50 dB), длительность 3–90 с.

## Правила

1. Всегда префлайт до работы.
2. Всегда показывать кандидатов и ждать выбора. Не рендерить без подтверждения.
3. Одна сцена HyperFrames — до 25 секунд, иначе упор в лимит рендера.
4. Подписи: два соседних блока не перекрываются по времени. Проверять арифметикой.
5. Не обещать транскрипт, если STT нет. Сказать честно и предложить SRT.
6. Чистить `_work/clips/` после сдачи только с разрешения.

## Ловушки песочницы

- `hyperframes.frames` требует ПАРАМЕТР `ffmpeg` с полным путём, иначе ошибка
  «не нашла ffmpeg.exe».
- Папка проекта называется по-русски; в HTML-композиции путь вида
  `../../projects/первый/_out/frames/...` — кириллицу писать как есть, файл в UTF-8.
- Импорт в библиотеку фильма ломается, если имя ассета уже занято (все сцены
  называются `film.mp4`). Копировать под уникальными именами.
- `node-real script.cjs | node-real -` не запускает ffmpeg (EPERM) — только `shell.run`.
