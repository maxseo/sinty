# Song Syllable Fit

Переписывает куплеты/предприпев песни так, чтобы каждая строка ложилась в заданное число слогов.

## Вход

- Исходный текст с разметкой секций ([Intro], [Verse], [Chorus], ...).
- Целевое число слогов (по умолчанию 6) и список секций, которые НЕ трогать (обычно [Chorus]).

## Правила

1. **Припев не трогать**, если не попросили. Дословно.
2. **Считать слоги по гласным.** В русском слог = гласная буква. е/ё/ю/я дают один слог, если не распадаются на два звука; в пении «я» часто = 2, поэтому строку лучше собирать с запасом из чистых гласных.
3. Одна строка = ровно N слогов. Проверять каждую, писать счёт рядом с текстом.
4. Сохранять: рифмовку (или её схему), смысл строки, порядок образов, разговорный тон автора.
5. Не тащить лишние слова-затычки («просто», «же», «вот») — от них строка раздувается.
6. Короткие слова лучше длинных: строка должна петься на одном выдохе.
7. Секции, которые не влезли в N, дробить на большее число строк, а не растягивать.

## Порядок работы

1. Разметить секции, отметить защищённые.
2. Для каждой строки посчитать слоги в оригинале (`scripts/count_syllables.py`).
3. Переписать строку, посчитать снова, при расхождении — править.
4. Сверить рифмы по парам строк в куплете.
5. Выдать полный текст с пометками `(N)` у переписанных строк и коротким списком, что изменилось.

## QC перед выдачей

- [ ] Ни одна строка не длиннее и не короче N.
- [ ] Припев совпадает с оригиналом посимвольно.
- [ ] Рифмы на местах.
- [ ] Нет повторов одного слова дважды в строке.
- [ ] Смысл не уехал: строка про то же, что и в оригинале.

## Счёт слогов скриптом

```
python scripts/count_syllables.py "Мне почти всё равно"
```
